# Changelog

## 1.0.0 — 2026-11-05

This is the first version of the revamp, running on the local site.

- Pages and Theme Builder templates rebuilt in Elementor V4, using the `tmc-*` design system.
- All live pages, posts, mats, accessories and URLs carried over.
- ACF content model: Mats, Accessories and Frames, Mat Categories, and the Mat Details, Accessory Details and Page Options field groups. The old JetEngine data was moved into ACF.
- WPCode snippets ("TMC: …"): mat and accessory content, Mat Finder, technical tables, form spam protection, content styles and the Site Guide.
- Project pages and blog posts converted from old Elementor layouts to plain editor content.
- Yoast SEO titles match live; Redirection rules for the live redirects. Complianz installed (wizard still to run).
